Parking Analytics Infrastructure

Built an automated parking data pipeline and KPI system using camera-based monitoring data.

Overview

This project connected data from garage entry, parking bay usage, and exit events into a full vehicle lifecycle.

Technical Work

  • API extraction and Python transformation
  • SQL storage and Jenkins scheduling
  • License plate matching logic
  • Power BI dashboards for leadership

Impact

Created new KPIs such as average time to park, average time to exit, garage emptying time, and parking utilization patterns.
