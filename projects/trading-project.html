Algorithmic Trading Bot

Personal project building an automated trading system using financial, behavioral, and alternative data signals.

Overview

The project combines data from multiple APIs, builds predictive signals, and executes weekly trades automatically.

Methods

  • Random Forest modeling
  • 10+ years of historical backtesting
  • Sharpe-ratio-based optimization
  • Automated execution with Alpaca API

Outcome

The strategy achieved a Sharpe ratio greater than 1.0 in backtesting and is run through an automated weekly workflow.
